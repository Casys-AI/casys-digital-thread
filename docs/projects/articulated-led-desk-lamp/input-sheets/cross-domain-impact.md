# G6 — cross-domain impact input sheet

Audience: human · Diátaxis: how-to · Kind: decision input

Status: `unknown` until one exact proposed change and its source-backed causal claims
are reviewed against current branch evidence.

## Change and causal map

| Required fact                                        | Human/source entry |
| ---------------------------------------------------- | ------------------ |
| Current product and Thread revision                  | `unknown`          |
| Exact proposed power or brightness change            | `unknown`          |
| Change source, revision, and fingerprint             | `unknown`          |
| Electrical inputs/artifacts affected and why         | `unknown`          |
| Thermal inputs/artifacts affected and why            | `unknown`          |
| Mechanical inputs claimed independent                | `unknown`          |
| Positive evidence supporting mechanical independence | `unknown`          |

## Consequences

| Required fact                                                     | Human/source entry |
| ----------------------------------------------------------------- | ------------------ |
| Expected electrical gate transition                               | `unknown`          |
| Expected thermal gate transition                                  | `unknown`          |
| Expected mechanical gate transition                               | `unknown`          |
| Required branch reruns, each through its own registered operation | `unknown`          |
| Intended impact decision and responsible reviewer                 | `unknown`          |

Silence is not independence. An unavailable electrical vertical remains `unavailable`;
an absent causal edge remains `impact-unresolved`. The impact decision itself does not
run ngspice, OpenModelica, or CalculiX and does not authorize hidden cascades.
