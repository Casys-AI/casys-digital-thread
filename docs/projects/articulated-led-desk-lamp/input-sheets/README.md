# AL01 human input sheets

Audience: human · Diátaxis: how-to · Kind: decision kit

Fill one sheet at a time. A blank field means `unknown`; it never authorizes an agent,
compiler, renderer, or solver to choose a replacement. Attach an exact source identity
where requested. The human reviews engineering meaning and consequence; the server later
owns provider selection, lowering, execution, capture, and recovery.

| Gate | Sheet                                         | Unlocks after review                                                              | Does not unlock                                              |
| ---- | --------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| G2   | [Mechanical arm](mechanical-arm.md)           | Canonical arm admission and a separately sealed static proof case                 | Thermal, electrical, Make, Buy, or a whole-lamp verdict      |
| G4   | [Thermal head](thermal-head.md)               | Admitted closed-subset Modelica source, run review, and later L4 review           | Automatic L5 or electrical power truth                       |
| G5   | [Electrical driver](electrical-driver.md)     | One reviewed circuit boundary and proof method when a registered operation exists | Provider/tool selection, safety, EMC, or thermal verdict     |
| G6   | [Cross-domain impact](cross-domain-impact.md) | Review of one exact proposed change and its declared causal map                   | Automatic reruns or mechanical independence without evidence |

The project asks these questions adaptively. Completing a Markdown sheet is source
material, not approval: the corresponding exact project proposal still requires the
normal human MRTR.
