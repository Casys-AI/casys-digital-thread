# PS-01 agent experience

Audience: agent · Diátaxis: explanation · Kind: AX observation

## What is pleasant now

- Bytes enter once through `project_resource_capture`; file and attachment identities
  stay stable while revisions advance.
- Eight bounded modules keep product, mechanical, behavior, electrical and verification
  files separate.
- Product navigation starts from SysML occurrences; source closure starts only from one
  exact attachment. The agent never loads a whole project manifest.
- `project_source_file_read` reopens old and current revisions. Search and tree return
  only the active head at the requested workspace revision.
- A verification-plan successor pins exact corrected source heads. Its closure returns
  five files and five explicit dependency edges.
- `deno task mcp:call --receipt` suppresses large mutation snapshots when only the human
  receipt is needed.

## Frictions found and treated

The first technical capture failed because a workspace classification
`modelica-source` was compared with the server profile's internal role
`modelica-model`. Those are different bounded-context facts. The profile now owns the
analyzer role and language; workspace `role` remains navigation metadata. Thread source
projection uses the sealed profile role.

The first CAD, Modelica and SPICE files were honest skeletons and the analyzers rejected
them. Successor revisions corrected the bytes without replacing the stable file or
attachment identities.

## Honest remaining limits

- The combined preview reports nine exact missing `AttributeUsage` joins. Adding those
  is a reviewed SysML architecture revision, not an MCP navigation fix.
- `ps01.diverter.cad` depends on `ps01.frame.cad`; deterministic multi-file CAD lowering
  is still `unavailable`. Root-only execution remains the covered path.
- Product-navigation calls deliberately carry a long exact architecture basis. Ready
  actions and bounded pages avoid guessing, but compact human CLI views still use `jq`.
- The read-only Workbench correctly shows the sealed SysML product and no geometry, but
  it does not yet project the draft source-workspace tree or its active revisions. That
  remains an agent MCP surface, not hidden Thread evidence.
