Brief activities of the same verification authority. It does not limit claims to the
selected L4 work item. There is no legal no-gate accept through that review for the
current Brief, and hand-editing its returned parameters would violate the exact review
contract. A zero-gate reject is a different human consequence, not a substitute for
accepting a bounded result.

contributes-to claims may become L5 satisfies claims; no L4 claims must mean a valid
no-gate accept. Review/executor agreement, refusal tests and completed historical replay
must be preserved. It does not add automatic product-scope matching; the Brief has no
exact product-scope field.

Terra review: a completed historical L5 carrying the former automatically generated
claims would be reinterpreted through the new derivation and fail before its replay
branch. The new-format zero-claim replay test did not cover that historical case. The
follow-up preserves exact sealed historical reopens while refusing new unsealed legacy
accepts. No first-pass code was copied into the running checkout.
