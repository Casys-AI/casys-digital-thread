## Review localization — resolved in current worktree

Thread, but exposed only its immutable content admission. An agent could therefore
copy the artifact's creation-snapshot reference while execution requires the artifact
localized on the exact run basis. The executor's fail-closed rule remains correct. The
proving run exposed the gap; current CAD, Modelica and SPICE reviews now return the
registered `operation` with `compilationAdmission` localized on the exact current
review basis. The cancelled first MCS-02 attempt remains historical evidence of the
former AX.

`source.dependency-lowering-unavailable`; the compiler may not ignore them.
