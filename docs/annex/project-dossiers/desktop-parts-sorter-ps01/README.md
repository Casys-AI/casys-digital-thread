# Desktop Parts Sorter PS-01

Audience: both · Diátaxis: none · Kind: project index

PS-01 is the current multi-piece authoring and MCP agent-experience proving project. It
tests whether an agent can start from a reviewed brief, create exact SysML product
structure, upload separate technical files, revise them incrementally and navigate the
result without a flat product manifest.

This is a supervised tabletop concept/integration proof. It is not a released sorter,
an assembly-geometry claim, a safety claim or an engineering verdict.
