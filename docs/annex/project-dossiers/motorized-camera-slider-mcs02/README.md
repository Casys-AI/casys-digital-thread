## Bounded story

Indoor tabletop demonstrator for a 2 kg provisional design payload. The reviewed
scenario asks three separate questions: whether one isolated RailFrame stays within the
declared static bounds, whether one scalar carriage model reaches 400 mm, and whether
one linear DC motor-phase equivalent stays within 2 A.

## Explicit exclusions

No complete multi-piece CAD assembly, placements, contacts, coupled simulation,
stepper torque, chopper or microstepping behavior, thermal behavior, controller
dynamics, safety, EMC, reliability, certification, manufacturing readiness, Make or
Buy, or whole-slider verdict.
